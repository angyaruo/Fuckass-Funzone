# v2.3.2 — Cabinet Glam

A presentation-first Plinko release focused on spectacle, clarity and machine personality. Gameplay rules, save format and fictional-ticket economy are unchanged.

## What changed

- Reframed Plinko as a tiny cabinet with a darker chamber, a house plaque and subtle stage trim.
- Upgraded payout bins so winning slots get stronger glow, outline and celebratory spark emphasis.
- Added an aim guide that reflects the current stake tier without blocking the pegfield.
- Repositioned monocled Gabu so he perches more convincingly off the cabinet edge.
- Refined the Plinko reaction bubble with a pop-in speech-bubble treatment.
- Tightened the wager / drop strip and reduced wager options to four readable choices: FREE, 1, 5 and 10.
- Preserved all prior gameplay behavior, save compatibility, and reaction logic.
